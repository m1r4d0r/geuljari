# 단계 계획

## 1단계 — 읽기 틀 (끝)
- 엔진: 글자 단위 시간표, 어절 역할, 쉼 완급, 블록 효과, 장면·바탕 표시, 페이지 나누기.
- 읽기 틀 2판: 페이지마다 장, 쓸기·스밈 넘김, 끌기·휠·키·단추, 길게 누르기, 페이지별 폭·자리, 초점 띠, 손끝.
- 바탕 다섯(창빛·한지·영사광·오로라·물빛), 가림판(■), 효과 견본, 반전 시험.

## 2단계 — 편집실
순서대로. 각 항목은 끝날 때마다 스모크를 돌린다.

1. `editor.html/css/js` 뼈대: 교정쇄 토큰(`docs/디자인-교정쇄.md`), 세 열 짜임, 모바일 쌓임. `base.css`의 1판 토큰은 가림판·견본에서만 쓰고 편집실은 새 `editor.css`에 둔다.
2. 편집창: 예시 글이 들어 있는 입력창. 구현 방식은 README Q-11을 먼저 정한다. 추천은 `textarea` + 뒤에 겹치는 표시 레이어(같은 글꼴·줄 간격으로 글자를 그려 쉼 네모·페이지 겹줄·강조 밑줄만 보이게). 붙여넣기·실행 취소·IME가 그대로 살아남는다.
3. 표시: 쉼(띄어쓰기 두 칸부터), 페이지 겹줄(빈 줄 둘), 문단 사이(빈 줄 하나), 강조(블록 문법), 장면 요약. 엔진의 `parse`를 그대로 써서 읽기 틀과 판정이 어긋나지 않게 한다.
4. 드래그 → 강조 판: 선택 범위를 블록 문법으로 감싼다(가림판 `applyEffect` 재사용). 효과 이름에 올리면 견본 줄에서 움직인다.
5. 페이지 겹줄에 올리면 넘김·장면·바탕 판: 장면 표시 줄(`[[밤:오로라]]`)을 그 자리에 넣거나 바꾼다. 넘김(스밈·쓸기)은 장면이 같을 때 쓸기를 강제할 수 있게 표시 문법을 하나 더 둔다(예: `[[쓸기]]`). 엔진에 추가 필요.
6. 조판 지정: 흐름(이어 쓰기·번짐·떠오름·타자 = 문단 기본 효과), 장면·바탕(첫 페이지), 속도·쉼·줄 간격, 먹 색, 소리. 값은 글 앞머리의 머리말(예: `[[설정: 속도=1.0, 쉼=0.3, 줄=2.05, 먹=쪽먹]]`)로 글과 함께 저장한다. 엔진에 추가 필요.
7. 미리보기(교정쇄): 읽기 틀을 축소해 넣는다. 현재 페이지만 다시 쓰기, 공목 모션 켜고 끄기.
8. 아래 막대: 결 막대, 집계(`stats`), 가린 글 복사(`mask`), 미리보기(새 창에서 읽기 틀로), 발행(3단계 전까지는 비활성).
9. 모바일: 설정 서랍, 길게 눌러 강조.
10. 소리: Web Audio로 빗소리·바람·밤벌레·낮은 울림, 종이·바늘 효과음. 첫 터치 뒤에만 켠다. 읽기 틀에도 같은 모듈(`sound.js`).

## 3단계 — 발행과 공유
- 저장: Firestore 문서 `{id, title, cipher, iv, pwHash, live, createdAt, updatedAt, meta?}`. `meta`는 결 보이기를 켤 때만(글자 수, 어절 길이 배열).
- 암호화: 브라우저 WebCrypto AES-GCM 256. 열쇠는 링크 조각(`#`), 서버로 가지 않는다. 비밀번호는 서버에서 해시(scrypt/argon2)만 저장하고 고치기·지우기·게시 토글에만 쓴다.
- Netlify Functions: `publish`, `load`(비밀번호 확인 뒤 암호문 반환), `update`, `delete`, `toggle`, `og`(제목+결로 PNG), `ask`(문의 → 디스코드 웹훅), `reply`, `admin-*`.
- 읽기 링크 `/t/{id}#{열쇠}`: 정적 뷰어가 암호문을 받아 브라우저에서 풀고 읽기 틀로 넘긴다. OG 메타는 함수가 제목만 넣어 돌려준다.
- 발행 창·발행 뒤·불러오기·지우기 확인·불러온 뒤 띠: 시안대로.
- 비밀번호 분실 정책은 README Q-1 결정 뒤 경고문에 반영.
- 타래 펴기의 `tarae-crypto.js`와 발행 함수를 참고한다(사용자가 제공).

## 4단계 — 문의와 관리실
- 문의 창(익명, 브라우저에 문의 id 저장, 이메일 선택), 디스코드 웹훅 알림, 관리실 답장.
- 관리실: 현황, 글 목록(제목·날짜·글자 수·열림·게시), 문의, 설정(웹훅·첫 인사말·관리자 비밀번호). 관리자 인증은 README Q-7.

## 5단계 — 다른 사람도 쓰게
- 상한·만료·신고 경로(README Q-5), 첫 화면(소개 + 편집실로), 사용법 한 장.
