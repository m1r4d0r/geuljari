# 디자인 명세 — 교정쇄

세 방향(서류·점·교정쇄) 중 사용자가 "일단 괜찮다"고 한 교정쇄의 명세다. 시안은 `../design/교정쇄-편집실.html`로 열어 볼 수 있다. 세부는 바뀔 수 있고, 바뀌면 이 문서를 먼저 고친다.

## 1. 생각
- 회색 종이 위의 교정쇄. 글은 활자로 놓이고, 아직 안 놓인 자리는 공목(빈 네모 □)이 채운다. 가린 글자 ■와 같은 네모다.
- 표시는 교정자가 연필로 적듯이: 강조는 물결 밑줄과 여백 메모, 쉼은 빈 네모, 페이지는 겹줄과 쪽 번호.
- 모노톤. 색은 연필 하나뿐이고 표시에만 쓴다. 면과 1px 선으로 나누고, 모서리는 모두 각지다. 테두리 상자와 둥근 모서리는 없다.

## 2. 색

| 이름 | 값 | 쓰임 |
|---|---|---|
| 종이 | `#E8E5DE` | 바탕 |
| 교정쇄 | `#F1EFE9` | 미리보기 장, 떠 있는 판 |
| 먹 | `#1B1A18` | 글자, 선, 채운 단추 |
| 납 | `#625E58` | 흐린 글씨, 이름표 (종이 위 대비 5.1:1) |
| 선 | `#C9C5BC` | 구분선 |
| 공목 테두리 | `#B9B4A9` | 빈 네모 |
| 고름 바탕 | `#D3CFC5` | 드래그 선택 |
| 연필 | `#A63C33` | 강조 밑줄, 여백 메모, 쉼 네모, 쪽 번호, 지우기 (종이 위 대비 5.0:1) |

읽기 화면의 종이·먹·젖은 먹은 장면(낮·밤)과 "먹 색"이 정한다. 낮 `#ECEFE9 / #1D2321`, 밤 `#0E1317 / #DCE1DA`. 젖은 글자는 모노톤에서는 옅은 먹(`#7A756D`)으로 시작해 마르며 진해진다. 먹 색을 고르면(검정·쪽먹 `#2B3A55`·갈먹 `#4A3A32`·회먹 `#625E58`·직접) 젖은 글자와 강조에만 그 색이 든다.

## 4. 짜임 (편집실, PC 1440)

```
[상단 52] 글결 ■□  편집                       불러오기  문의
[왼쪽 여백 250 | 교정 열 ≤700 가운데 | 교정쇄 430]
  교정 부호(규칙 셋)   재단선 ⌐ ¬          교정쇄 한 장(재단선)
  조판 지정            제목 ───────         안 쓰인 글은 □
   흐름 □■ / 장면      본문 (송명)          쪽 눈금 ■□□□□ 1/5
   바탕 / 슬라이더 3    강조 ~~~ 떠오름     견본 한 줄 · 다시
   먹 ■■■■□ / 소리      ═══ 2  쓸기→밤
[아래 56] 결 ▌▌▌ ▌▌  966자 · 5페이지 · 43초     가린 글 복사  [미리보기] [발행]
```

- 규칙 셋은 설명이 아니라 부호와 한 줄로: `□□ 띄어쓰기 두 번 — 한 호흡 쉼`, `═ 빈 줄 둘 — 새 페이지 · 빈 줄 하나는 문단 사이`, `~~ 끌어서 고르기 — 강조`.
- 편집창 안에서도 같은 부호로 보여 준다. 그래서 설명이 짧아도 된다.
- 모바일(390): 상단 → 규칙 한 줄 → 편집창 → 미리보기(아래, 접을 수 있음) → 설정 서랍 손잡이 → 아래 막대. 강조는 길게 눌러 고른다.

## 5. 부품

- **고르기**: `□ 이름` 세로 목록 또는 가로 줄. 고른 것은 `■`. 글자색은 고른 것만 먹, 나머지 납.
- **슬라이더**: 1px 선에 9px 네모 손잡이. 값은 오른쪽에 나눔고딕코딩.
- **스위치**: 쓰지 않는다. 켜고 끄는 것도 `□/■`로.
- **단추**: 채움(먹 바탕·교정쇄색 글자) = 발행. 선(1px 먹) = 미리보기·그만두기. 글자만(밑줄) = 가린 글 복사·다시. 지우기는 연필색 선.
- **입력 칸**: 밑줄 하나. 제목은 송명 24px.
- **떠 있는 판**(강조 고르기, 페이지 넘김 고르기): 교정쇄색 바탕에 1px 먹 선, 안에 `□/■` 고르기. 그림자 없음.
- **페이지 선**: 3px 겹줄(`border-top: 3px double`), 왼쪽에 연필색 쪽 번호, 오른쪽에 넘김·장면·바탕 요약(납).
- **쉼 표시**: 연필색 빈 네모 8px, 띄어쓴 수만큼(최대 넷).
- **강조 표시**: `text-decoration: underline wavy` 연필색, 밑줄 띄움 5px, 뒤에 효과 이름(나눔고딕코딩, 연필색).
- **재단선**: 네 귀퉁이 14px 꺾쇠, 1px 먹.
- **결 막대**: 어절마다 글자 수만큼 막대(3px 폭), 어절 사이 4px. 글의 모양을 내용 없이 보여 준다. 아래 막대와 링크 카드에 쓴다.
- **공목**: 8px 빈 네모, 글자 수만큼, 띄어쓰기는 5px 빈 자리.

## 6. 움직임
- 전체 원칙은 README R-5: 낮밤 반전만 휙, 나머지는 느리고 손을 따라온다.
- 공목→글자: 네모가 사라지며 글자가 제자리에서 떠오른다(기존 `rise`/`soft`와 같은 시각, 750ms). 젖은 색에서 마른 색으로 1~2초.
- 미리보기와 견본 줄은 읽기 틀의 `GeulFx.timeline`을 그대로 써서 읽기 화면과 똑같이 움직인다.
- 설정을 바꾸면 견본 줄만 바로 다시 쓰고, 미리보기는 현재 페이지를 처음부터 다시 쓴다.

## 7. 브랜딩
- 로고: 원고지 네 칸 `글|자|리|.` 송명, 1px 먹 칸. 넷째 칸은 비워 두고 왼쪽 아래에 연필색 마침표(원고지에서 마침표가 앉는 자리). 글자는 송명 윤곽을 패스로 바꾼 SVG(`logo.svg`)라 글꼴이 늦거나 없어도 모양이 같다. 작은 데에서는 ■□만.
- 파비콘: 네모 하나 안에 결 한 줄(SVG) 또는 ■□. SVG 하나로 16·32·180.
- 사이트 제목 `글자리`. 설명 `글이 써지는 속도와 숨을 그대로 보여 주는 글 틀`. 링크 제목 `{글 제목} · 글자리`.
- 링크 카드 1200×630(읽기 틀의 끝 장, `ending.js`): 끝 장 바탕의 멈춘 한 장면 위에 제목을 가장 크게(본문 글꼴, 100→86→74px, 두 줄까지·넘치면 줄임표), 제목이 없으면 첫 문장. 맨 아래 가운데에 ■□ 글자리와 만든 날(나눔고딕코딩). 글의 결(■ 패턴)을 넣을지는 발행 때 정한다.

## 8. 화면 목록 (만들 것)
1. 편집실 PC·모바일
2. 발행 창(제목·비밀번호·바로 게시·결 보이기·경고 동의)
3. 발행 뒤(링크·비밀번호 한 번만·열쇠 내려받기·게시 토글)
4. 불러오기 창(링크·비밀번호·열쇠 파일 끌어 놓기), 불러온 뒤 띠, 지우기 확인
5. 읽기 화면(기존 읽기 틀 + 아주 작은 글결 표시 + 문의 열기)
6. 문의 창
7. 관리실(현황·글 목록·문의·설정)

첫 안의 색면 시안(캔버스 위쪽 줄)은 쓰지 않는다. 짜임의 참고로만 남겨 둔다.
