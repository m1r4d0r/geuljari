# 미리보기 여백 색인

2026-10-11 사용자 승인 방향. 다른 작업이 진행 중이므로 `codex/geuljari-margin-index`에서만 작업하고 main에는 병합하지 않는다.

## 화면과 동작

- 헤더는 단계 이동을 맡는다. 편집 / 미리보기 / 발행을 각 화면에서 계속 보여 준다.
- 후속 요청으로 발행 단계를 연결했다. `/t/` 링크·저장소 구성은 [발행](발행.md)을 따른다. 목표는 Netlify Functions + Blobs이며 현재 Firestore 어댑터는 전환 대상이다.
- 오른쪽 여백 색인은 분위기 / 글씨 / 움직임 / 배경 네 항목만 담는다.
- 항목을 누르면 폭이 넓어지고 바로 아래 설정이 펼쳐져 다음 항목을 아래로 민다. 같은 항목을 다시 누르면 접힌다. 한 번에 하나만 열린다.
- 다시 보기 / 숨기기 / PC·폰·병렬 전환은 미리보기 하단바에 놓는다.
- 모바일은 오른쪽 위 ‘다듬기’로 색인을 열고 같은 펼침 동작을 사용한다. 긴 설정은 색인 전체를 스크롤한다.
- 숨기기는 헤더·색인·하단바를 함께 거두며 작은 꺼내기 단추로 복원한다.
- 설정을 여닫을 때 읽기 틀의 크기와 배율은 유지한다.
- 이름은 글자리로 확정됐다. 이 대화의 초기 로고 시안은 채택하지 않았고, 최신 main에는 다른 작업의 글자리 로고가 있다. 이 브랜치 제품 코드에는 아직 합치지 않았다.

## 병합할 때 확인할 부분

- `index.html`: 패널 네 개를 각각 `.index-item` 아래로 옮겼다. 기존 패널 ID와 `.panel-body`는 유지한다. `#back`은 헤더의 편집 단계 버튼이다.
- `index.css`: 세로 책갈피·옆 패널·모바일 하단 패널 스타일을 여백 색인으로 교체했다. `.panel-fold`의 높이와 항목 왼쪽 여백을 보간한다.
- `panels.js`: 실제 설정 렌더러는 유지한다. 닫는 동안 조작·접근성 노출을 즉시 차단하고 접힘 애니메이션 뒤 hidden을 적용한다. 다시 연 판에는 이전 닫힘 예약이 적용되지 않는다.
- `index.js`: 색인의 aria-expanded, 모바일 메뉴, 헤더·하단바 숨기기를 연결한다. 모바일 하단 패널 위치에 맞춰 미리보기를 줄이던 로직과 패널 크기 관찰은 제거했다.
- 새 단계가 추가되면 `STEPS`, `setStep`, 헤더 `.steps`를 함께 확인한다. 발행 저장 로직은 `publish.js`와 서버 모듈로 분리했다.

## 확인

`tests/smoke_margin_index.py`는 PC, 폰, 좁은 폰, 낮은 가로 화면에서 펼침·빠른 전환·기존 글자 크기 반영·헤더 복귀·숨기기·동작 줄이기를 확인한다. 실제 설정값은 예시 글로만 확인한다.

```sh
python3 tests/smoke_margin_index.py /tmp/geulteul-margin-check
```

Playwright Chromium이 별도 경로에 있으면 `CHROMIUM` 환경 변수로 지정한다. 기존 편집실 스모크는 `tests/smoke_studio.py`다.
