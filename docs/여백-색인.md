# 미리보기 여백 색인

2026-10-11 사용자 승인 방향. 12:35 후속 지시로 병렬 작업 보류를 해제하고 최신 main의 로고·효과와 함께 통합·배포한다.

## 편집 설정 서랍

PC에서는 분위기·테마를 오른쪽 칸에 표시한다. 760px 이하 모바일에서만 `#write-settings` 서랍으로 접으며, 헤더 설정 버튼으로 연다. native dialog의 닫기·Escape·바깥 누르기로 복귀한다. 화면 크기가 바뀌면 같은 설정 DOM을 옮기므로 두 벌의 입력값이 어긋나지 않는다.

불러오기·안내·새로 쓰기는 서랍 밖 헤더에 둔다. 세 줄 입력법은 본문 위에 항상 표시한다. 첫 방문에도 편집창이 바로 보이고 도움말은 ‘안내’로 연다. 예시 글 버튼은 제거하며 자료는 테스트에만 사용한다. 단계 이동은 상단에만 두고 편집 하단바에는 글자·쪽 수만 표시한다. 저장·불러오기 및 관리 파일 형식은 기존대로 유지한다.

## 화면과 동작

- 헤더는 단계 이동을 맡는다. 편집 / 미리보기 / 발행을 각 화면에서 계속 보여 준다.
- 후속 요청으로 발행 단계를 연결했다. `/t/` 링크·저장소 구성은 [발행](발행.md)을 따른다. Netlify Functions + Blobs로 전환했다.
- 오른쪽 여백 색인은 분위기 / 글씨 / 움직임 / 배경 네 항목만 담는다.
- 서랍 안의 항목을 누르면 바로 아래 설정이 펼쳐져 다음 항목을 아래로 민다. 같은 항목을 다시 누르면 접힌다. 한 번에 하나만 열린다.
- 다시 보기 / 몰입 / 끝 장 카드 / PC·폰·병렬 전환은 미리보기 하단바에 놓는다.
- PC·모바일 모두 오른쪽 가장자리의 가느다란 손잡이를 누르거나 안쪽으로 끌어 서랍을 연다. 손잡이는 잠깐 안쪽으로 움직여 방향을 알리며 동작 줄이기에서는 멈춘다. 닫기·Escape로 닫고 손잡이에 초점을 돌린다. 긴 설정은 색인 전체를 스크롤한다.
- 몰입은 헤더·색인·하단바를 함께 거두며 작은 꺼내기 단추로 복원한다.
- 설정을 여닫을 때 읽기 틀의 크기와 배율은 유지한다.
- 이름은 글자리로 확정됐다. 이 대화의 초기 로고 시안은 채택하지 않았고, 최신 main에는 다른 작업의 글자리 로고가 있다. 현재는 최신 main의 로고도 제품 코드에 합쳤다.

## 파일과 구조

- `index.html`: 패널 네 개를 각각 `.index-item` 아래로 옮겼다. 기존 패널 ID와 `.panel-body`는 유지한다. `#back`은 헤더의 편집 단계 버튼이다.
- `index.css`: 세로 책갈피·옆 패널·모바일 하단 패널 스타일을 여백 색인으로 교체했다. `.panel-fold`의 높이를 보간한다. 서랍은 읽기 틀 위에 겹친다.
- `panels.js`: 실제 설정 렌더러는 유지한다. 닫는 동안 조작·접근성 노출을 즉시 차단하고 접힘 애니메이션 뒤 hidden을 적용한다. 다시 연 판에는 이전 닫힘 예약이 적용되지 않는다.
- `index.js`: 색인의 aria-expanded·hidden·inert, 가장자리 손잡이, 헤더·하단바 숨기기를 연결한다. 모바일 하단 패널 위치에 맞춰 미리보기를 줄이던 로직과 패널 크기 관찰은 제거했다.
- 새 단계가 추가되면 `STEPS`, `setStep`, 헤더 `.steps`를 함께 확인한다. 발행 저장 로직은 `publish.js`와 서버 모듈로 분리했다.

## 확인

`tests/smoke_margin_index.py`는 PC, 폰, 좁은 폰, 낮은 가로 화면에서 펼침·빠른 전환·기존 글자 크기 반영·헤더 복귀·숨기기·동작 줄이기를 확인한다. 실제 설정값은 예시 글로만 확인한다.

```sh
python3 tests/smoke_margin_index.py /tmp/geulteul-margin-check
```

Playwright Chromium이 별도 경로에 있으면 `CHROMIUM` 환경 변수로 지정한다. 기존 편집실 스모크는 `tests/smoke_studio.py`다.

`tests/editor-visibility.cjs`는 다섯 화면 크기에서 안내·보조 메뉴 노출, 모바일 전용 서랍, 리사이즈 복귀, 파비콘 참조, 중복 버튼 제거와 기존 저장·불러오기를 확인한다.
